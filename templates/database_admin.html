Production Setup

Connect a Real Cloud Database

When deployed on Vercel Serverless, local SQLite in /tmp is ephemeral. Connecting a real cloud database (PostgreSQL or MySQL) ensures that all enrolled learners, attendance scans, parent accounts, and billing transactions persist permanently in real time across all devices.

1-Click Recommended

Option A: Vercel Postgres

Zero configuration. Vercel provisions a serverless Neon PostgreSQL cluster and links environment variables automatically.

  1. Open your Vercel Dashboard.
  2. Click project deped-smile → Storage tab.
  3. Click Create Database → Select Postgres (Neon).
  4. Click Continue → Select region (Singapore / AP-Southeast).
  5. Click Connect to Project → Done!

Auto-links POSTGRES_URL & auto-deploys!

Free Forever

Option B: Neon PostgreSQL (neon.tech)

Generous free tier (0.5 GB, 1 project). Fast serverless cold starts with instant connection pooling.

  1. Create free account at neon.tech.
  2. Click New Project → Select region Singapore.
  3. Copy the Connection String: postgresql://user:pass@ep-xyz.neon.tech/neondb?sslmode=require
  4. In Vercel → Settings → Environment Variables: Add DATABASE_URL.
500 MB Free

Option C: Supabase PostgreSQL

Full enterprise PostgreSQL instance with direct URL and automated SSL certificates.

  1. Sign in at supabase.com.
  2. Click New Project → Set database password.
  3. Go to Project Settings → Database → URI.
  4. Copy the URI and set as DATABASE_URL in Vercel.
On-Premises

Option D: MySQL / XAMPP (Local LAN)

Ideal for school computer labs or local campus servers without constant internet access.

# In phpMyAdmin / MySQL CLI:

CREATE DATABASE deped_smile;

# In smile_config.py or .env:

DATABASE_TYPE = "MYSQL"

MYSQL_URL = "mysql+pymysql://root:@localhost:3306/deped_smile"

You do not need to write SQL migration scripts or create tables manually. Project S.M.I.L.E.'s SQLAlchemy ORM automatically builds all 9 database tables, indexes, relations, default DepEd class sections, and the Super Admin account the very first second the cloud database connects!
